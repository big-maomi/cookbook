# 🍳 新鲜香草番茄意面

> **来源:** [Recipe30 · Joel Mielle](https://recipe30.com/fresh-herb-tomato-pasta.html/) · recipe30.com

## 📋 食材清单

### 主料

- [ ] **意面** — **340 克**（原方 12 盎司，意大利面或你喜欢的种类均可）
- [ ] **樱桃番茄** — **500 克**（原方 18 盎司，切四瓣）

### 辅料

- [ ] **大蒜** — **3 瓣**（切薄片）
- [ ] **新鲜罗勒叶** — **360 毫升**（原方 1½ 杯，撕碎）
- [ ] **新鲜欧芹** — **120 毫升**（原方 ½ 杯，切碎）
- [ ] **新鲜牛至** — **60 毫升**（原方 ¼ 杯，切碎）
- [ ] **帕玛森奶酪碎** — *可选*

### 调料

- [ ] **橄榄油** — **75 毫升**（原方 5 汤匙）
- [ ] **盐和黑胡椒** — 适量
