# 🍳 普罗旺斯焗蔬菜

> **来源:** [Recipe30 · Joel Mielle](https://recipe30.com/gratin-provencale.html/) · recipe30.com

## 📋 食材清单

### 主料

- [ ] **西葫芦** — **5 个**（中等大小）
- [ ] **番茄** — **5 个**（中等大小）
- [ ] **茄子** — **2 个**
- [ ] **蘑菇** — **370 克**（原方 13 盎司）
- [ ] **洋葱** — **1 个**（棕皮洋葱）
- [ ] **大蒜** — **2 瓣**
- [ ] **新鲜罗勒叶** — **1 把**

### 辅料

- [ ] **意式番茄泥（passata）** — **240 毫升**（原方 1 杯）
- [ ] **切达奶酪碎** — **约 55 克**（原方 半杯）
- [ ] **帕玛森奶酪碎** — **约 50 克**（原方 半杯）
- [ ] **面包糠** — **约 55 克**（原方 半杯）

### 调料

- [ ] **橄榄油** — **120 毫升**（原方 ½ 杯）
- [ ] **普罗旺斯香草** — **1 小勺**（5 毫升）

---

## 👨‍🍳 烹饪步骤

### 步骤 1

取 **3 个**西葫芦切成中等大小的丁；蘑菇和洋葱也切碎，大蒜擦成蒜末。全部放入炒锅或大号深锅中，加入普罗旺斯香草，用盐和黑胡椒调味，**中火**煸炒并焖煮，直到水分**几乎完全收干**。盛出稍微放凉。

### 步骤 2

与此同时，把茄子**削去一半外皮**（留出条纹），切片后用橄榄油刷匀。放入平底锅或烤盘上煎，**两面**都煎熟。盛出备用。

### 步骤 3

将意式番茄泥与少许橄榄油、撕碎的罗勒叶、普罗旺斯香草、盐和黑胡椒拌匀，备用。

### 步骤 4

把剩余的西葫芦切片，放入拌菜盆中，加橄榄油、盐和黑胡椒抓拌，让每片都**均匀裹上油**。备用。

### 步骤 5 ⏱ 45 分钟（烤制）

在烤盘中按以下顺序铺层：刷一层橄榄油 → 铺**一半**茄子片 → 撒帕玛森奶酪碎 → 铺番茄片 → 铺**一半**蔬菜炖料 → 淋**一半**番茄泥酱汁 → 盖上剩余茄子片 → 再撒帕玛森奶酪碎 → 铺剩余蔬菜炖料 → 抹上剩余番茄泥酱汁 → 铺番茄片 → 最上层把**生的**西葫芦片按你喜欢的方式交叠排好。撒上面包糠，再铺上切达奶酪碎（也可以再擦一点帕玛森奶酪）。放入烤箱以 **175℃**（原方 350℉）烤 **45 分钟**。出炉后放凉 **20–30 分钟**再上桌，撒上新鲜撕碎的罗勒叶即可。
